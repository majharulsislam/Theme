NexBlocks is a premium multipurpose WordPress theme featuring 12 header layouts, 12 footer layouts, and 25+ professionally designed page templates.

== Description ==

NexBlocks is a premium multipurpose WordPress theme built for agencies, businesses, portfolios, and WooCommerce stores. It includes multiple header and footer layouts switchable from the Customizer, a full set of page templates, accessibility-ready navigation, and WooCommerce compatibility.

Key Features:
* 12 switchable header layouts (Phase 2)
* 12 switchable footer layouts (Phase 3)
* 25+ page templates
* Customizer with live preview
* WooCommerce compatible
* Accessibility-ready (WCAG 2.1 AA)
* RTL language support
* Translation-ready (.pot included)
* No jQuery dependency
* Performance-optimized (deferred JS, lazy images)

== Installation ==

1. In your WordPress admin panel, go to Appearance > Themes.
2. Click "Add New" and then "Upload Theme".
3. Upload the nexblocks.zip file.
4. Click "Activate".
5. Go to Appearance > Customize to configure header, footer, colors, and typography.
6. Import demo content via Tools > Import (optional, requires WordPress Importer plugin).

== Frequently Asked Questions ==

= How do I switch the header layout? =
Go to Appearance > Customize > Header > Header Layout and choose from the available header styles.

= How do I switch the footer layout? =
Go to Appearance > Customize > Footer > Footer Layout and choose from the available footer styles.

= Is NexBlocks compatible with WooCommerce? =
Yes. NexBlocks includes WooCommerce-specific styles for the shop, single product, cart, and checkout pages.

= How do I add widget content to the footer? =
Go to Appearance > Widgets and add widgets to Footer Column 1–4.

= Is child theme support available? =
Yes. All paths use get_template_directory() and get_theme_file_uri() so child themes work correctly.

= Does the theme support RTL languages? =
Yes. An rtl.css file is included and automatically loaded for RTL languages.
