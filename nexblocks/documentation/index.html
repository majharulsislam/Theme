NexBlocks — Theme Documentation

Version 1.0.0 | Author: iNeedMarketer | License: GPL v2+

Quick Start: Install the theme, activate it, then go to Appearance › Customize to set your header, footer, colors, and typography.

1. Installation

  1. Download the nexblocks.zip file from ThemeForest.
  2. In WordPress admin, go to Appearance › Themes › Add New › Upload Theme.
  3. Upload the zip file and click Install Now.
  4. Click Activate.
  5. Go to Appearance › Customize to configure the theme.

2. Demo Content Import

  1. Install the WordPress Importer plugin (Tools › Import › WordPress).
  2. Upload demo-content/demo.xml.
  3. Import the customizer settings via the Customizer Export/Import plugin using demo-content/customizer.dat.
  4. Import widgets via Widget Importer & Exporter plugin using demo-content/widgets.wie.

3. Switching Headers

Go to Appearance › Customize › Header › Header Layout. Select a header style from the image picker. Changes preview live in the customizer.

4. Switching Footers

Go to Appearance › Customize › Footer › Footer Layout. Select a footer style and optionally customize the copyright text.

5. Adding New Headers (Developer)

  1. Create template-parts/headers/header-N.php
  2. Create assets/css/headers/header-N.css
  3. Add a thumbnail assets/images/pattern-thumbnails/header-N.jpg (300×200px)
  4. The header auto-registers — no PHP edits needed.

6. Adding New Footers (Developer)

Same pattern as headers but in the footers/ directories.

7. Customizer Options

  • General › Layout — Sidebar position (left/right/none), container width
  • Header — Header layout, sticky header, transparent header
  • Footer — Footer layout, copyright text
  • Colors — Primary, secondary, accent, text, heading, background
  • Typography — Body font, heading font, base font size

8. Widget Areas

  • Blog / Page Sidebar
  • WooCommerce Sidebar
  • Footer Columns 1–4
  • Header Top Bar Left / Right
  • 404 Page Widget

9. WooCommerce

NexBlocks automatically detects WooCommerce and loads WooCommerce-specific styles. No additional setup required. Add WooCommerce sidebar widgets via Appearance › Widgets › WooCommerce Sidebar.

10. Page Templates

When editing a page, look for the Page Attributes › Template dropdown. Available templates (Phase 4 adds 25+ templates).

11. Menus

Go to Appearance › Menus. Create menus and assign them to locations: Primary, Secondary, Mobile, Footer Columns 1–3, Social Links.

12. Building from Source

npm install
npm run dev    # development build with watch
npm run build  # production minified build
npm run pot    # regenerate .pot translation file
